対戦テトリス

友達と1対1。片方が部屋を作って、出てきた数字4桁のコードを相手に伝えるだけで始まります。

押すと「ポロン」と鳴ります。鳴らないときは、iPhone なら本体横のマナーモードのスイッチと音量を確かめてください。

未接続

通常は変更不要です。無料サーバーは使われていないと眠るため、最初の接続に最大1分ほどかかることがあります。

・ラインを消すと相手におじゃまブロックを送れます
・T-Spin、連続消し（REN）、テトリスで威力アップ
・相手から届いたおじゃまは、自分が消せば打ち消せます
・ただし4秒たつと問答無用でせり上がります（カウントダウンが出ます）
・全消し（パーフェクトクリア）は特大の10段
・「ひとりで遊ぶ」は10ライン消すごとに落下が速くなるマラソンです
・操作は左手が移動（◀ ▼ ▶）、右手が回転（↺ ↻）です
